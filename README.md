# Nébula · IrisSystem V1.0.0

Aplicación experimental multiplataforma desarrollada con Flutter.

## Demo

https://nebulairissystem.netlify.app/

## Tecnologías

- Flutter
- Dart
- just_audio
- audio_service
- just_audio_windows
- Visualizador reactivo
- CMake para Windows

## Plataformas

- Android
- Windows
- Web

## Funciones

- Reproductor de música local
- Importación de archivos de audio
- Visualizador de partículas
- Fondo de nebulosa
- Juego espacial abstracto
- Ajustes de accesibilidad
- Reproducción en segundo plano en Android

## Descargas disponibles:
- 📱 **Android**: nebula.apk
- 💻 **Windows**: nebula.exe
- 🌐 **Web Local**: Página web incluida
